# VENA - Blood Bank Operations Platform

Plataforma SaaS de gestion de inventario de hemocomponentes para bancos de sangre privados en Venezuela.

## Que hace
- Registro y autenticacion de instituciones de salud
- Gestion de inventario de hemocomponentes con trazabilidad completa
- Alertas automaticas de stock minimo y vencimientos proximos
- Red VENA: visualizacion del stock de otras instituciones registradas en tiempo real

## Stack tecnologico
- React + Vite (frontend)
- Supabase (base de datos y autenticacion)
- Netlify (despliegue)
- Claude Code (construccion del codigo)
